## Notas
**“Inspect source”** (o _“ver código fuente”_) de una página web es la opción que te permite ver el **código HTML, CSS y JavaScript** con el que está hecha una página.

Cuando entras a una página (por ejemplo, Google o Facebook) tú ves el diseño ya procesado. Pero detrás de eso hay código que el navegador interpreta para mostrar todo.
